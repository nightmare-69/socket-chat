# 🚀 Socket Chat - Quick Start Guide

## Download & Extract

1. **Download** `socket-chat.rar` from the provided link
2. **Right-click** the RAR file → **Extract here** (or use WinRAR/7-Zip)
3. A folder named `socket-chat` will appear

---

## What You Get After Extraction 📂

```
socket-chat/
├── node_modules/          ← [Auto-generated] All dependencies
├── public/                ← [Folder] Frontend files
│   └── index.html         ← [File] Chat UI
├── package.json           ← [File] Project config
├── package-lock.json      ← [File] Dependency lock file
└── server.js              ← [File] Backend code
```

### What Each Folder/File Does:

| Item | Purpose |
|------|---------|
| **node_modules/** | Contains all npm packages (express, socket.io). Don't touch this! |
| **public/** | Folder with all frontend files (HTML, CSS, JS for the browser) |
| **public/index.html** | The chat interface you see in the browser |
| **package.json** | Configuration file (project name, dependencies, scripts) |
| **package-lock.json** | Lock file ensuring everyone installs same versions |
| **server.js** | The backend logic (handles rooms, messages, connections) |

## Next Steps 🎬

### Step 1: Open Terminal/Command Prompt

**Windows:**
1. Press `Win + R`
2. Type `cmd`
3. Click OK

**Mac:**
1. Press `Cmd + Space`
2. Type `terminal`
3. Press Enter

### Step 2: Navigate to the Folder

In terminal, type:
```bash
cd Downloads/socket-chat
```

(Or wherever you extracted it)

### Step 3: Start the Server

Type:
```bash
npm start
```

You should see:
```
Chat running at http://localhost:3000
```

✅ **Server is now running!**

### Step 4: Open in Browser

1. Open your browser
2. Go to `http://localhost:3000`
3. Open another tab/window and go to the same URL
4. Enter different names, same room code, and chat! 💬

## File Breakdown 🔍

### `server.js` (3 KB)
The brain of the app. Contains:
- Express server setup
- Socket.IO connection handling
- Room management (max 2 people)
- Message broadcasting
- Typing indicators
- User join/leave logic

### `public/index.html`
The chat UI. Contains:
- Join screen (name + room input)
- Chat screen (messages + input)
- Styling (dark theme)
- Client-side Socket.IO code

### `package.json` (1 KB)
Project metadata. Tells npm:
```json
{
  "name": "socket-chat",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  },
  "dependencies": {
    "express": "^4.19.2",
    "socket.io": "^4.7.5"
  }
}
```

When you run `npm install`, it reads this and downloads the libraries listed.

### `package-lock.json` (38 KB)
Automatically generated lock file. Ensures everyone installs exact same versions. Don't edit!

### `node_modules/` (Folder)
Auto-generated by `npm install`. Contains thousands of files from express and socket.io libraries. **Never commit to GitHub, never edit!**


## Troubleshooting 🔧

| Problem | Solution |
|---------|----------|
| "npm: command not found" | Install Node.js from nodejs.org |
| "Port 3000 already in use" | Close other apps or use different port |
| "Cannot find module 'express'" | Run `npm install` |
| "Can't connect from phone" | Same Wi-Fi + use your PC's IP address |
